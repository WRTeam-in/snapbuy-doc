General Settings — Flutter App

This section covers the core configuration every buyer needs to rebrand, connect, and publish the SnapBuy Flutter apps. Each topic below applies to the Customer App unless a page states otherwise — the same topics for the Delivery App are documented on its own General Settings page.

Before You Begin

Complete these in order, before touching any of the settings below:

  • Install Flutter SDK, Java JDK, and an IDE and confirm flutter doctor -v passes with no errors.
  • Have your Admin Panel already installed and reachable — the apps talk to it over HTTPS.
  • Create a Firebase project (or have one ready) — Firebase powers authentication, push notifications, and OTP for both apps.
  • Decide your package name (e.g. com.yourcompany.snapbuy) before running Firebase registration — registering under the wrong package name means redoing that step later.
  • Have your app icon, name, brand color, and legal pages (Privacy Policy / Terms) ready — you'll need them during setup.
