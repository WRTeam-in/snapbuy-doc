Notification Settings

Configure push notifications across the admin panel, Firebase, Android, and iOS so users receive real-time updates from the app. This covers Firebase Cloud Messaging (FCM) setup in three places: the Admin Panel, Android, and iOS.

1. Admin Panel Configuration

The app must be registered with Firebase first — see Firebase Setup. Then gather two values from the Firebase Console:

  1. Firebase Project ID — Project Settings → General tab → Project ID.
  2. Service Account File — Project Settings → Service accounts tab → click Generate new private key to download a JSON file.

Upload the downloaded JSON file and enter the Project ID in your Admin Panel → Settings → Firebase Settings to complete notification setup.

Warning

Keep the Service Account JSON file private — it grants server-level access to your Firebase project. Never commit it to a public repository.

2. Android Setup

All necessary dependencies, service classes, and configurations are already included in the Flutter project — no additional coding is required. You only need to:

  1. Download google-services.json from Firebase Console (Project Settings → General → Your apps → Android app).
  2. Place it at android/app/google-services.json, replacing any existing file.

3. iOS Setup

Basic Configuration

  1. Open ios/Runner.xcworkspace in Xcode.
  2. Under Signing & Capabilities, enable Push Notifications.
  3. Under Background Modes, enable Remote notifications and Background fetch.
  4. Replace or add GoogleService-Info.plist at ios/Runner/GoogleService-Info.plist.

APNs Authentication

Firebase needs an APNs credential to deliver notifications to iOS devices. Two methods are supported:

Token-based (.p8) — preferred:

  1. Log in to the Apple Developer Portal.
  2. Under Certificates, Identifiers & Profiles → Keys, create a new key with Apple Push Notifications service (APNs) enabled.
  3. Download the .p8 file — it can only be downloaded once, so store it safely.
  4. Note the Key ID and your Team ID (found in your Apple Developer account's Membership details).
  5. In Firebase Console, go to Project Settings → Cloud Messaging → Apple app configuration and upload the .p8 file with its Key ID and Team ID.

Tip

The .p8 token-based method is preferred over .p12 certificates — tokens don't expire and a single key works for both development and production.

Certificate-based (.p12) — alternative:

  1. Create a Certificate Signing Request (CSR) using Keychain Access on a Mac.
  2. In Apple Developer Portal, generate a Development or Production SSL certificate using the CSR.
  3. Download the certificate and export it as a .p12 file from Keychain Access.
  4. Download and install the matching Provisioning Profile in Xcode.
  5. Upload the .p12 file(s) to Firebase Console under Cloud Messaging → Apple app configuration.
