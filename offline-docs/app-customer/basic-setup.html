Basic Setup Guide

This guide takes you from a fresh machine to the Customer app running against your Admin Panel — installing the toolchain, opening the project, and confirming the first successful launch.

1. Install Flutter SDK

Download the latest stable release of Flutter SDK (from official release channels).

  • Extract the ZIP archive into your development folder (e.g., C:\flutter on Windows or ~/flutter on macOS/Linux).
  • Add Flutter executable to your system environment PATH:
    • Windows: Environment Variables > System Variables > Path > Add C:\flutter\bin.
    • macOS / Linux: Open ~/.zshrc or ~/.bashrc and add: 
      export PATH="$HOME/flutter/bin:$PATH"
  • Verify the installation: 
    flutter doctor -v

2. Install Java JDK

Download and install Java Development Kit (JDK 21 LTS) from Oracle or OpenJDK.

  • Set up the JAVA_HOME environment variable pointing to your JDK installation directory.
  • Add %JAVA_HOME%\bin (Windows) or $JAVA_HOME/bin (macOS/Linux) to your PATH.
  • Verify Java version in terminal: 
    java -version

3. Setup IDE & Android Tools

  • Android Studio: Install Android Studio, open SDK Manager, and install Android SDK Platform 34+ and Command-line Tools.
  • VS Code: Install the official Flutter and Dart extensions from Marketplace.

4. Open the Project & Install Dependencies

  1. Extract the Customer app source you downloaded from CodeCanyon into a working folder — e.g. snapbuy-customer/.
  2. Open that folder in Android Studio or VS Code.
  3. From the project root, fetch all Dart/Flutter package dependencies: 
    flutter pub get
  4. iOS only — install CocoaPods dependencies: 
    cd ios
pod install
cd ..

Warning

flutter pub get must complete without errors before continuing. A version conflict here (shown as "Because ... depends on ...") means your installed Flutter/Dart SDK version doesn't match what the project expects — check Prerequisites for the exact version this app was built against.

5. Point the App at Your Backend

Before the app can log in or load products, it needs your Admin Panel's URL. This is configured in lib/core/configs/app_config.dart via the env/ JSON files.

Full details — config keys, environments, the sync script — are covered in Panel URL & Deeplink. At minimum, edit env/demo.json and set:

{
  "BASE_URL": "https://your-admin-panel-domain.com/customer/"
}

then run the sync script from the project root:

dart run tool/apply_config.dart

6. Run the App

  1. Start an Android emulator, connect a physical device (USB debugging enabled), or open an iOS Simulator.
  2. List available devices to confirm one is detected: 
    flutter devices
  3. Launch the app: 
    flutter run

What "done" looks like

The app builds, installs, and opens to the SnapBuy splash/onboarding screen without a red error screen, and the home screen loads categories or products from your Admin Panel — confirming BASE_URL is reachable and correctly set.

Verify Installation

Run the following command in your terminal to confirm your toolchain itself is installed correctly:

flutter doctor -v

All checks should pass (green check marks) before moving to the next step.
