Advertisement

Monetize the Customer App with banner, interstitial, or rewarded ads using either Unity Ads or Google AdMob.

Customer App only

This feature applies to the Customer App. The Delivery App does not display advertisements.

1. Unity Ads

Create a Unity Project

  1. Sign in (or create an account) at the Unity Ads dashboard.
  2. Create a new project with your app's details.
  3. Open Unity Ads Monetization in the project settings.
  4. Choose a monetization option:
    • I will use Unity Ads — Unity's own ad network only.
    • I will use Mediation — combine Unity with multiple ad networks.
  5. If prompted, choose whether to copy ad settings from an existing project.
  6. Select My app is not live yet if you haven't published, and add the project. Store IDs (Play Store / App Store listing IDs) can be added later once the app is live.

Integrate Unity Ads

  1. In Unity's dashboard, copy your Game ID (separate IDs for Android and iOS) and ad Placement IDs (banner, interstitial, rewarded).
  2. In your Admin Panel, go to Settings and add the Unity Ad IDs.
  3. Save. Your app is now ready to display Unity Ads.

Enable Test Mode

  • In your Unity project, open the Testing section and force test mode on.
  • Add specific testing devices:
    • Android: Settings → Google → Ads → find your Advertising ID.
    • iOS: use a third-party utility app to locate your device's advertising identifier.

Turn off test mode before release

Forgetting to disable test mode means real ads never serve (or revenue isn't counted) in production. Always turn test mode off before submitting to the stores.

2. Google AdMob

Create an Account & Register the App

  1. Go to the AdMob Console and sign in with your Google account.
  2. Complete onboarding: enter your account details and accept the terms.
  3. Add an app for Android and a separate app for iOS.
    • If the app is already published, search for it by name in the respective store.
    • If it isn't published yet, enter the details manually.

Unpublished app validation

Published apps validate automatically once the AdMob SDK is integrated and ads are requested. Unpublished apps must be manually validated — install the build on a physical device and launch it with the SDK active. You'll also need to host an app-ads.txt file at your domain root to authorize your ad inventory for sale.

Get the App ID

Each platform's app receives an App ID from AdMob's App settings page, in the format:

ca-app-pub-XXXXXXXXXXXXXXXX~YYYYYYYYYY

Add the App ID to Your App

Android — add to android/app/src/main/AndroidManifest.xml inside <application>:

<meta-data
    android:name="com.google.android.gms.ads.APPLICATION_ID"
    android:value="ca-app-pub-XXXXXXXXXXXXXXXX~YYYYYYYYYY"/>

iOS — add to ios/Runner/Info.plist:

<key>GADApplicationIdentifier</key>
<string>ca-app-pub-XXXXXXXXXXXXXXXX~YYYYYYYYYY</string>

Create Ad Units

In AdMob, create a separate Ad Unit for each format you plan to use — Banner, Interstitial, Rewarded, and Native. Each ad unit gets its own ID in the format ca-app-pub-XXXXXXXXXXXXXXXX/ZZZZZZZZZZ.

Configure in the Admin Panel

Enter the generated Ad Unit IDs into the corresponding fields in your Admin Panel ad settings, then save. If ads fail to display after saving, double-check that each ID was copied without extra spaces and that the matching ad unit's status in AdMob is Active.

Tip

AdMob also has its own test ad unit IDs — use those during development so you don't risk invalid-traffic flags on your real ad units before launch.
