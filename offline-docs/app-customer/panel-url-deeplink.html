Base URL & Deeplink Setup

Configure the backend API URL and deeplink (Universal Link / App Link) settings used by the app.

Overview

All backend API and deeplink config lives directly in lib/core/configs/app_config.dart as Dart constants — no env/ JSON files involved. Edit the file, then run the sync script to propagate values into the native Android / iOS config.

Config Keys

lib/core/configs/app_config.dart:

ConstantMeaning
baseUrlBackend API root for all network calls
webUrlWeb app URL
socketBaseUrlSocket server URL used for real-time connections
deeplinkSchemeCustom URL scheme (e.g. snapbuy → snapbuy://product/123)
deeplinkHostUniversal / App Link host — must match the web app host (e.g. snapbuy.wrteam.me)

Example — lib/core/configs/app_config.dart:

abstract final class AppConfig {
  static const String baseUrl = 'https://admin-snapbuy.wrteam.me/customer/';
  static const String webUrl = 'https://snapbuy.wrteam.me';
  static const String socketBaseUrl =
      'wss://admin-snapbuy.wrteam.me:8080/app/w73uw1egonunwexdhebg';

  static const String deeplinkScheme = 'snapbuy';
  static const String deeplinkHost = 'snapbuy.wrteam.me';
}

How to Change Values

Step 1 — Edit app_config.dart

Open lib/core/configs/app_config.dart and update baseUrl, webUrl, socketBaseUrl, deeplinkScheme, and deeplinkHost directly.

Step 2 — Run Sync Script

From the project root:

dart run tool/apply_config.dart

The script reads app_config.dart and patches:

  • Android <data> intent-filter tags in AndroidManifest.xml (scheme + host; pathPattern is preserved)
  • iOS CFBundleURLSchemes first entry in Info.plist (the Google Sign-In reverse-client-ID below is left untouched)
  • iOS applinks:<host> entry in Runner.entitlements

Step 3 — Rebuild

flutter clean && flutter run

Files Involved

FilePurpose
lib/core/configs/app_config.dartSource of truth — edit this directly

ios/Runner/Runner.entitlementsiOS Universal Links

Important Notes

Warning

  • deeplinkHost must match the web app domain for iOS Universal Links and Android App Links to work.
  • deeplinkScheme is the scheme value used for deeplinking, and it must be same in app settings and in web app. (dont change unless you want)
  • webUrl must match the deeplinkHost domain (e.g. https://<deeplinkHost>).

Tip

After changing any value in app_config.dart, rerun the sync script → rebuild the app.

Panel-Side Deeplink Setting

The scheme configured above must also be set in the Admin Panel, and the Play Store / App Store URLs must be added so external links redirect correctly:

SettingMenu path
Deeplink SchemaSystem Setting → General Setting → Deep Link Settings
Play Store & App Store URLsSystem Setting → App Setting → App URL

Full details, testing commands, and a troubleshooting table are on the Admin Panel — Deeplink Settings page.

Keep the scheme identical everywhere

The deeplinkScheme value in app_config.dart, the Admin Panel's Deeplink Schema field, and the compiled Android/iOS apps must all match exactly. A mismatch breaks deeplinks silently — taps simply do nothing.
