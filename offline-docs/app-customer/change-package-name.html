Change Package Name

Update the default package name to your own unique identifier before publishing the app to the Play Store / App Store.

Please visit our Change Package Name Documentation for detailed instructions on changing the package name.

After changing the package name, you need to rerun the below commands to update the package references.

flutter clean
flutter pub get

Update Firebase after changing the package name

If Firebase is already configured, changing the package name/bundle ID invalidates the existing google-services.json / GoogleService-Info.plist. Re-register the app (or re-run flutterfire configure) under the new identifier — see Firebase Setup.
