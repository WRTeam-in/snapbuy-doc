Change Package Name

Update the default package name to your own unique identifier (Application ID on Android, Bundle Identifier on iOS) before publishing the app to the Play Store / App Store.

Package names identify your app uniquely on app stores — reusing the default risks publishing errors and installation conflicts. Use reverse-domain notation, e.g. com.yourcompany.appname, lowercase letters and dots only, and keep it consistent across Android, iOS, and Firebase.

1. Automated CLI Method (Recommended)

Add change_app_package_name to your pubspec.yaml:

dev_dependencies:
  change_app_package_name: ^1.1.0

Run the package command with your new domain-reversed package name:

dart run change_app_package_name:main com.yourcompany.appname

The command updates the package name in both platforms' build files and moves the Android Kotlin/Java package directories automatically.

2. Manual Method

If you prefer changing values manually, update the package string in the following files:

  • android/app/build.gradle > applicationId "com.yourcompany.appname" and namespace "com.yourcompany.appname"
  • android/app/src/main/AndroidManifest.xml > package="com.yourcompany.appname"
  • ios/Runner/Info.plist > CFBundleIdentifier
  • ios/Runner.xcodeproj/project.pbxproj > PRODUCT_BUNDLE_IDENTIFIER
  • Refactor package directory tree under android/app/src/main/kotlin/com/yourcompany/appname/

Tip

If your reversed domain contains a Kotlin reserved keyword (e.g. in), wrap that segment in backticks: package `in`.co.mydomain.myapp.

3. Clean & Rebuild

flutter clean
flutter pub get

Update Firebase after changing the package name

If Firebase is already configured, changing the package name/bundle ID invalidates the existing google-services.json / GoogleService-Info.plist. Re-register the app (or re-run flutterfire configure) under the new identifier — see Firebase Setup.

Tip

Double-check every file listed above after either method — a stale package name in even one file causes signing mismatches or install conflicts when publishing.
