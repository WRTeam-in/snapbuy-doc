Firebase Billing Setup

Firebase provides a range of services, some of which require billing to be enabled — especially OTP login, Google Maps, and the Places API. Follow these steps to ensure proper billing setup.

1. Upgrade from Spark to the Blaze Plan

Note

If you already set up the Blaze plan earlier (for Firebase OTP, for example), you don't need to repeat these steps — just confirm your billing account is still linked to the project.

  1. Log in to the Firebase Console (console.firebase.google.com) and open your project.
  2. In the bottom-left corner, your project shows the Spark plan. Click Upgrade.
  3. Select the Blaze plan.
  4. Select a billing account, then click Continue and Purchase. Your project is now on the Blaze plan.

Tip — creating a billing account

If you don't have a Google Cloud billing account yet: select your actual country (not a placeholder like India), choose an existing payment profile or create a new one, then add your payment details and select or add a payment method. See Google's billing account guide for the full walkthrough.

2. Set Up Billing for Map & Place API Keys

Step 1 — Link a Billing Account

Note

If billing is already linked from the OTP setup above, skip this step.

  1. Go to the Firebase Console and select your project.
  2. In the left-hand menu, click Project Settings.
  3. Under the Billing section, click Go to Billing Account.
  4. If you don't have a billing account, click Create Billing Account and follow the prompts to add a payment method.
  5. Link the billing account to your project.

Step 2 — Enable Required APIs

  1. In the Firebase Console, go to Project Settings → Cloud Messaging → Manage Service Accounts.
  2. Click through to Google Cloud Console and select the same project.
  3. In Cloud Console, navigate to APIs & Services → Library.
  4. Enable each of the following APIs:
    • Maps SDK for Android — displays maps on Android devices
    • Maps SDK for iOS — displays maps on iOS devices
    • Geocoding API — converts addresses into coordinates (optional)
    • Places API — location search and autocomplete
    • Routes API — calculates distance between locations
    • Maps JavaScript API — displays maps on the web portal

Warning

The Distance Matrix API is deprecated — enable the Routes API instead for distance/ETA calculations.

Step 3 — Set Up API Keys

  1. In Cloud Console, navigate to APIs & Services → Credentials.
  2. Click Create Credentials and select API Key.
  3. For each newly created key (Android, iOS, and Place Search), open its settings and remove any restrictions — skip this if the key is already unrestricted.

Step 4 — Add the API Key to Your App

Android — insert into android/app/src/main/AndroidManifest.xml:

<meta-data
    android:name="com.google.android.geo.API_KEY"
    android:value="YOUR_ANDROID_MAP_API_KEY" />

iOS — insert into ios/Runner/AppDelegate.swift:

GMSServices.provideAPIKey("YOUR_IOS_MAP_API_KEY")

Step 5 — Verify Billing Setup

  • In Cloud Console, go to Billing and confirm the project is linked to your billing account.
  • Test OTP, Map, and Place features in your running app to confirm each one works.
