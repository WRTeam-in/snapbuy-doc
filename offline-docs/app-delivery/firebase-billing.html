Firebase Billing Setup

To enable certain Firebase services (Phone OTP verification, Places search, Maps APIs beyond the free tier), you must upgrade your Firebase project to the Blaze (pay-as-you-go) plan and attach a billing account.

Please visit our Firebase Billing Setup Guide and follow every step in the order shown.

What the Guide Covers

  • Upgrading the Firebase project from Spark to Blaze
  • Linking or creating a Google Cloud billing account
  • Enabling required Google Cloud APIs (Maps SDKs, Places, etc.)
  • Creating and configuring API keys
  • Verifying that billing is correctly linked
