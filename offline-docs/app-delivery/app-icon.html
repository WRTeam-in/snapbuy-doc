App Icon

Replace the default SnapBuy Delivery launcher icon with your own brand icon on both Android and iOS.

Applies to both apps

Apply these steps to both the Customer App and Delivery App. Use a different icon for each so delivery partners and customers can tell the two apps apart on the home screen.

1. Prepare Your Icon

  • Create a square PNG, 512×512 px or larger (1024×1024 recommended).
  • Use a transparent or solid background — solid is safer for iOS, which does not support transparency in the App Store icon.
  • Keep the main artwork inside the center ~80% of the canvas so it isn't clipped by adaptive-icon masks on Android.

2. Automated Method (Recommended)

Add the flutter_launcher_icons package to pubspec.yaml:

dev_dependencies:
  flutter_launcher_icons: any

flutter_launcher_icons:
  image_path: "assets/icon/app_icon.png"
  android: true
  ios: true
  remove_alpha_ios: true
  adaptive_icon_background: "#FFFFFF"
  adaptive_icon_foreground: "assets/icon/app_icon_foreground.png"
KeyMeaning
image_pathPath to your 512×512 (or larger) source icon, used for both platforms
iosSet true to generate the full iOS AppIcon.appiconset
remove_alpha_iosStrips transparency for App Store compliance — iOS icons must be fully opaque
adaptive_icon_backgroundBackground color/image behind the Android adaptive icon
adaptive_icon_foregroundForeground artwork for the Android adaptive icon (optional)

Place your source image at assets/icon/app_icon.png, then run:

flutter pub get
dart run flutter_launcher_icons

Rebuild the app to see the new icon:

flutter clean
flutter pub get
flutter run

3. Manual Method

If you prefer not to use the package, replace the platform icon files directly.

Android — replace every density folder under:

android/app/src/main/res/mipmap-mdpi/
android/app/src/main/res/mipmap-hdpi/
android/app/src/main/res/mipmap-xhdpi/
android/app/src/main/res/mipmap-xxhdpi/
android/app/src/main/res/mipmap-xxxhdpi/

Each folder contains ic_launcher.png at a different resolution — keep the filenames and only swap the image content.

iOS — replace the icon set at:

ios/Runner/Assets.xcassets/AppIcon.appiconset/

Open this folder in Xcode's asset catalog editor and drag your icon into each required slot, or generate the full set with an online icon-set generator and copy the files in.

Warning

Always run flutter clean after changing icons — Android and iOS build caches frequently keep the old icon otherwise.
