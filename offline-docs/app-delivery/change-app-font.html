Change App Font

Swap the default font for one of your choice across the entire app. The app uses the google_fonts package, so no font files need to be added manually.

Step 1 — Update the Font in app_config.dart

Open lib/core/configs/app_config.dart and change the fontFamily value to the Google Font of your choice:

// App-wide font family
static final String? fontFamily = GoogleFonts.instrumentSans().fontFamily;

Replace instrumentSans() with any font method available in the google_fonts package, for example:

static final String? fontFamily = GoogleFonts.poppins().fontFamily;

Step 2 — Rebuild

flutter pub get
flutter clean && flutter run

The new font should now be applied across all screens.

TIP

Browse fonts.google.com to preview fonts, then use the matching method name from the google_fonts package (e.g. Poppins → GoogleFonts.poppins()).
