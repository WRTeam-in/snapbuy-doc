Assets Management

Assets are the images, animations, and other bundled resource files used inside the app — onboarding artwork, empty-state illustrations, icons, and Lottie/Rive animations. Managing them correctly keeps the UI looking sharp without breaking any code references.

Applies to both apps

Apply these steps to both the Customer App and Delivery App.

1. Images (SVG, PNG, JPG)

  • Replace an image using the exact same filename and extension as the original — this way no Dart code needs to change.
  • Keep the new image's dimensions and aspect ratio close to the original to avoid stretched or cropped UI.
  • If you rename the file or change its format (e.g. PNG → SVG), update every reference to it in the Dart code — search the lib/ folder for the old filename.
  • Some PNGs ship in multiple density variants for sharper rendering on high-DPI screens: 
    assets/images/banner.png       (1x)
assets/images/2.0x/banner.png  (2x)
assets/images/3.0x/banner.png  (3x)
    Either replace all variants with matching-resolution artwork, or delete the 2.0x / 3.0x folders and let Flutter fall back to the single 1x file.

2. Animations (Lottie, Rive)

  • Flutter supports Lottie (.json) and Rive (.riv) animation files, typically found under assets/animations/.
  • Replace an animation file using the same filename to avoid touching any widget code.
  • To use a different filename, locate the widget that loads it (search for Lottie.asset( or RiveAnimation.asset( in lib/) and update the path there.
  • Edit or create new animations with:
    • LottieFiles Editor — for .json Lottie animations
    • Rive Editor — for .riv animations

3. Registering New Assets

If you add a brand-new file (rather than replacing an existing one), declare it in pubspec.yaml under the flutter: assets: section, then run:

flutter pub get

Final Check

Always verify that new or updated assets have correct references in the code — a mismatched filename or an undeclared path in pubspec.yaml causes a missing-asset error at runtime, not at build time.
