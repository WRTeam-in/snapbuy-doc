# Integrate Facebook App Events

Track in-app user actions (installs, purchases, add to cart, etc.) via Facebook App Events for ad campaign measurement and audience building.

If you want to add these, follow our [Facebook App Events Documentation](https://marketplace.wrteam.in/docs/flutter-common-doc/GeneralSettings/facebook-app-events) and follow **every step in the order shown**.
